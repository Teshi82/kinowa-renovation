プライバシーポリシー

デモサイトでの入力情報と、外部サービスの利用についてご案内します。

本サイトは架空企業「木の輪リフォーム」のポートフォリオ作品です。実際の工事受付や相談サービスは提供していません。

1. フォームに入力する情報

フォームでは氏名、メールアドレス、電話番号（任意）、希望する工事内容、お問い合わせ内容、同意の状態を入力できます。これらは、お使いのブラウザー上で入力チェックの動作を体験するためだけに使用します。実際の個人情報を入力する必要はありません。

2. 外部送信と保存について

フォームの入力内容は外部へ送信しません。サイトのプログラムは、入力内容をCookie・localStorage・sessionStorageなどに保存しません。運営者が入力内容を受け取る仕組みはありません。ブラウザー自身の入力補完や復元などは、利用者のブラウザー設定に依存します。

3. 解析・広告・外部コンテンツ

この作品にはアクセス解析ツール、広告用の追跡プログラム、外部フォント、埋め込み動画、地図を導入していません。写真とスクリプトはサイト内のファイルを使用します。外部サイトへのリンクを開いた場合は、リンク先の方針が適用されます。

4. 公開基盤による情報の取り扱い

GitHub Pagesなどの公開基盤では、IPアドレスを含むアクセス情報がサービス提供・保護などのために処理される場合があります。詳細はGitHubのプライバシーに関する声明をご確認ください。

5. 本方針の見直し

実際の送信機能や外部サービスを追加する場合は、利用目的、保存期間、問い合わせ先などを定め、本方針を見直す必要があります。
